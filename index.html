Fargate Memos Deployment

Built and deployed the Memos application as a containerised workload on AWS, using Docker, Amazon ECR, ECS/Fargate, Application Load Balancer (ALB), ACM and HTTPS with a custom domain. Configured the supporting VPC, subnets, route tables, security groups, target groups and health checks to securely route traffic to the application running on ECS.

The project follows a ClickOps → Terraform → CI/CD approach, using the initial manual deployment to understand the AWS architecture before reproducing it as Infrastructure as Code and automating deployments.
